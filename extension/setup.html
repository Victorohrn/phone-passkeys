Set up Phone Passkeys

Use the passkeys on your phone or tablet by scanning a QR code, in Zen and Firefox on Linux.

Native host

Checking…

The extension needs a small helper program on your computer. It generates the QR code, listens for your phone over Bluetooth and relays the sign-in through the vendor's secure tunnel. Browser extensions cannot use Bluetooth on their own.

1. Requirements

  • Linux with Bluetooth turned on (BlueZ). Bluetooth is only used to confirm the phone is nearby.
  • A phone or tablet with passkeys: Android (Google Password Manager) or iPhone/iPad (iCloud Keychain).
  • To build the helper: Rust (cargo), pkg-config, OpenSSL and D-Bus development headers.

2. Install the native host

Get the source and run the installer. It builds the helper and registers it with the browser (under ~/.mozilla/native-messaging-hosts).

git clone https://github.com/Victorohrn/phone-passkeys.git
cd phone-passkeys
./install.sh --host-only

Prebuilt binaries, when available, are listed on the project's releases page.

3. Check and try it

Click Check again above. When the host is found, open webauthn.io and choose Register or Authenticate. A window with a QR code appears; scan it with the phone that holds your passkey.

Until the host is installed, passkey requests are handed back to the browser unchanged, so security keys and everything else keep working.

Privacy

The extension collects no data and contacts no servers itself. During a sign-in the native host talks to the tunnel server of your phone's vendor (Google or Apple) exactly as Chrome does; everything inside the tunnel is end-to-end encrypted between this computer and your phone. The host may also fetch /.well-known/webauthn from a site to honour its related origins.
